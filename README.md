# 2026-1 딥러닝 팀프로젝트 

## FallGuard
열화상 카메라 기반 멀티모달 욕실 낙상 감지 및 알림 시스템<br><br>


## 프로젝트 배경 및 목적

  최근 1인 가구의 비율 증가로 인해 주거 공간 내 응급 상황 발생 시 즉각적인 도움을 받기 어려운 사례가 증가하였다. 특히 욕실은 물기로 인한 미끄러짐, 좁은 공간 구조 등으로 인해 낙상 사고 위험이 높은 공간으로, 사고 발생 시 외부에 알릴 수단이 없는 경우가 많았다. 
<br><br>
  이에 본 프로젝트는 1인 가구 환경에서 욕실 내 사고 발생 시 사용자가 휴대전화를 소지하지 않아도 자동으로 구조 요청이 이루어지는 딥러닝 기반 안전 관리 시스템을 개발하는 것을 목적으로 하였다. 욕실 내 위험 상황을 자동으로 감지하고, 사전에 등록된 보호자 및 119에 즉시 알림을 전송함으로써 1인 거주자의 안전 문제 해결에 기여하고자 하였다.
<br>

### 역할분담
| 이름 | 역할 |
| --- | --- |
| 손서진 | 위험 탐지 이미지 모델 개발 |
| 양나은 | 위험 탐지 오디오 모델 개발 |
| 정윤진 | 알림 시스템 및 이벤트 처리 로직 구현 |
| 김수연 | 데이터 수집 및 전처리 |<br><br>
